# Dataset Information

This project evaluates deep learning models on standard fundus photography datasets for glaucoma detection:

- **ACRIMA**: Spanish retinal image database with 705 fundus images classified as normal or glaucomatous.
- **ORIGA**: Online Retinal Fundus Image Database for Glaucoma Analysis (650 images annotated by trained clinicians).
- **Fundus Train/Val Data**: Combined and augmented retinal dataset for multi-class/binary classification.

## Directory Structure
```
data/
├── raw/            # Place unzipped raw datasets here (ACRIMA, ORIGA, etc.)
└── processed/      # Auto-generated by running src/data/dataset_loader.py
```

## Setup Instructions
1. Download the datasets from their respective public repositories or research portals.
2. Extract the image folders into `data/raw/`.
3. Run the dataset preprocessing pipeline:
   ```bash
   python src/data/dataset_loader.py
   ```
